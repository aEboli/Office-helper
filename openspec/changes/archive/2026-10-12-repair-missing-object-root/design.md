# 设计

## 调用恢复

- `AgentRunner` 解析出 `excel_object` 参数后，若 `root` 缺失或为空，先发出原有工具卡，再请求面板补充对象入口。
- 桥接层以原工具调用 ID 关联等待中的请求，只允许 `workbook`、`worksheet`、`window` 三个值；取消返回空值。请求等待绑定当前对话取消令牌，并在任务结束或面板关闭时收束。
- 用户选择后，`AgentRunner` 写入同一个参数对象，通知面板刷新原卡片参数，然后沿原有审批和执行路径继续。工具调用 ID 不变，因此原生协议的工具结果仍与助手调用配对。
- 用户显式取消时通过同一调用 ID 回传结构化失败结果，不批准、不执行。停止或面板关闭取消等待；面板可见时将待处理卡片标为未执行。

## 面板交互

- 等待状态显示在对应工具卡片中，卡片自动展开。
- 显示“当前工作簿”“当前工作表”“当前窗口”三个明确选项及取消入口。
- 选择后禁用选项并显示等待执行状态；收到参数更新时，原卡片显示补齐后的 `root`。

## 安全与边界

- 不根据工具参数或请求内容猜测 `root`，不对模型提供的其他参数作修改。
- 桥接层和 `AgentRunner` 都验证允许值；无效值不进入执行。
- 缺少 `range` 等其他必需参数继续返回原有 `ARG_MISSING`，不弹出补全卡。

## 验证

- OpenSpec 严格校验通过。
- 桥接测试覆盖合法选项、非法值拒绝和取消令牌收束。
- 面板测试覆盖同一工具卡显示选项、提交选择、取消和更新后的参数。
- .NET 构建、定向测试、前端语法检查及 `git diff --check` 通过。
