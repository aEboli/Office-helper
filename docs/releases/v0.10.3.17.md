# v0.10.3.17 草稿预览与模型能力适配

本版本把 Word/WPS Writer 的生成式写入改为先预览、再确认，并补充模型不支持原生工具调用时的协议回退。

## Word 草稿预览

- 起草、续写和生成式改写先生成侧栏草稿，生成和调整阶段不修改当前文档。
- 草稿使用受限的语义结构，可预览标题、分级标题、段落、项目符号、编号列表、表格、引用以及加粗/斜体文字。
- 预览提供沿用文档、简洁、商务和报告四种版式，可继续通过自然语言调整内容与设计。
- 用户确认插入或替换后，系统重新核对文档身份、Story 和选区，再按现有审批、保护检查和读回规则执行。
- 丢弃草稿不改文档；结构化写入只有在快照能完整恢复时才提供撤销，不能完整恢复时会明确显示不可撤销。

## 模型能力适配

- 自动记录当前连接与模型的工具协议能力，服务商拒绝工具字段时在同一步切换到文本指令协议。
- 模型回复明确表示不支持工具或函数调用时，也会切换到文本指令协议；普通安全拒绝不会误触发。
- DeepSeek Flash/V4 Flash 变体在自动模式下首轮直接使用文本指令协议，手动选择原生函数调用仍保持优先。
- 文本协议继续复用原生工具的审批、参数校验、操作卡片和撤销边界。
