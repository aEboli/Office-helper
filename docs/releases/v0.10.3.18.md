# v0.10.3.18 Excel 对象入口修复

修复模型发出 `excel_object` 调用但遗漏必需 `root` 参数时，工具直接失败且用户无法补全的问题。

- 工具卡暂停并提供“当前工作簿”“当前工作表”“当前窗口”三个对象入口。
- 用户选择后补全原调用参数，沿用相同调用 ID，并继续现有参数校验、审批和执行。
- 用户取消返回未执行结果；停止或关闭面板会收束等待并确保该调用不执行。
- 其他缺失参数仍按原有错误处理。
