# ChatSheet v0.1.0

`v0.1.0` 是 ChatSheet 的首个公开发行版本。它将 Windows 原生 COM Excel 加载项、WebView2 本地侧边栏、模型协议适配和受控 Excel 工具以可核验的预构建 ZIP 形式发布。

## 发行资产

| 文件 | 用途 |
| --- | --- |
| `ChatSheet-v0.1.0-win.zip` | Windows 预构建安装包；内含加载项、依赖、安装脚本、安装说明、发行说明和包内 SHA-256 清单 |
| `ChatSheet-v0.1.0-win.zip.sha256` | ZIP 整体 SHA-256 校验文件 |

完整安装、校验、升级和卸载步骤见 [Windows 发行包安装说明](../windows-release-install.md)。

## 发布前验证边界

在生成此发行包的维护环境中，以下检查已通过：

- `dotnet clean .\ChatSheet.sln --configuration Release --nologo`
- `dotnet build .\ChatSheet.sln --configuration Release --nologo`（0 个警告、0 个错误）
- `tests\ChatSheet.ToolTests\bin\Release\ChatSheet.ToolTests.exe`（206 通过、0 失败；会启动并关闭独立 Excel 实例）
- `node tests\web\markdown.test.mjs`（24 通过、0 失败）
- `node tests\web\imports.test.mjs`（14 通过、0 失败）
- 发行 ZIP 的解压布局、18 个运行时载荷文件、22 条包内 SHA-256 清单、最终 DLL 哈希、脚本 UTF-8 BOM，以及发行包中只读 `diagnose`/预构建载荷识别路径。

这些检查证明源代码、包内文件和脚本布局在该维护环境中一致；它们**不**替代在新的 Windows 机器上完成实际 UAC 安装，也不替代用户在自己的 Excel、组织策略、模型服务和工作簿中进行手工验收。

## 本版提供的能力

- 在 Windows 桌面版 Microsoft Excel 中加载 ChatSheet Ribbon 和右侧 WebView2 对话面板；运行时不启动项目 Node.js 服务，也不监听本地端口。
- 通过 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 或 Google Gemini 协议接入模型；支持流式文本、工具调用、思考档位和在模型支持时的图片输入。
- 读取工作簿结构、选区与范围；在明确审批下写入值或公式、设置格式、清除范围、排序、新建/重命名工作表、创建表格和图表。
- 对可记录的操作提供撤销/恢复辅助，并对值/公式写入进行读回验证。
- 使用 Windows DPAPI `CurrentUser` 保护自定义 API 密钥；WebView2 页面 CSP 禁止页面自身直接联网，模型请求由加载项进程发送。
- 发行包安装不需要 .NET SDK：解压后直接运行同一套 PowerShell 安装脚本即可。

## 安全与兼容性边界

- 仅支持 Windows 桌面版 Microsoft Excel；不支持 WPS 表格、Excel 网页版或 Excel for Mac。
- 需要 .NET Framework 4.8、Microsoft Edge WebView2 Runtime 和 UAC 管理员授权。管理员权限用于机器级托管 COM 注册，Excel 加载项登记仍只影响当前用户。
- ZIP 不是 MSI/EXE，也没有代码签名、自动更新或静默安装功能。下载后请先验证 SHA-256。
- 单次读取上限为 2,000 个单元格；写入、格式、清除、自动调整和排序的单次上限为 5,000 个单元格。
- 默认是逐项审批。设置中的“每轮确认”尚未实现独立的预检语义；在完成专项验证前，请使用默认逐项审批或在需要时明确选择“本轮全部允许”。
- 打包与自动化测试不等同于所有用户环境中的实际 Excel 加载或真实模型服务验收。重要工作簿请先备份并人工复核。

## 从 v0.1.0 安装

1. 在 [GitHub Release](https://github.com/aEboli/Office-helper/releases/tag/v0.1.0) 下载 ZIP 与 `.sha256` 文件。
2. 比较 ZIP 的 SHA-256 与 sidecar 内容。
3. 解压 ZIP，关闭 Excel，并从解压根目录运行：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1 -Action install
   ```

4. 接受 UAC 提示，重新打开 Excel，再在 **ChatSheet** 选项卡中打开面板。

本次发行所对应的源码版本由 Git 标签 `v0.1.0` 固定。Release 页面提供的 ZIP 和 sidecar 将与该标签指向的提交一起核验。
