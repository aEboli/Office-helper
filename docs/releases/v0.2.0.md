# ChatSheet v0.2.0

`v0.2.0` 是 ChatSheet 的第二个公开版本。它在 `v0.1.0` 的 Windows 原生 Excel 加载项基础上，补齐接入重试与模型选择链路，更新面板交互、文本文件附件和表格适配工具，并修复从面板回到工作表后键盘焦点仍停留在 WebView2 的问题。

## 发行资产

| 文件 | 用途 |

## 接入与模型选择

- 模型请求和模型列表请求会按错误类型处理临时故障；网络错误、`408`、`429` 和常见 `5xx` 状态可重试，退避期间在面板显示次数、等待时间和原因，明确的配置或鉴权错误不会盲目重试。
- 设置页获取到的模型目录按接入连接缓存并由对话页复用，避免在两个页面重复请求；对话页的刷新按钮仍是明确的强制重新加载。
- 模型与接入连接绑定。切换协议、地址或本机 CLI 来源后，旧连接留下的模型不会继续冒充当前模型；切回原连接时可继续使用为该连接确认过的选择。
- 不提供 `GET /models` 的网关可以直接手填模型 ID，并通过 Enter 或“使用”按钮应用。

## 面板与输入

- 输入区改为单行图标化操作栏：发送/停止合并为三态按钮，新会话使用清理图标，适配操作使用三向图标；长模型 ID 会截断，不再把窄面板工具栏撑成多行。
- 文本文件可以直接粘贴或拖入输入框。面板按 BOM、UTF-8 和 GBK/GB18030 识别常见中文文本编码，非 UTF-8 编码会显示在附件条上。
- 文件附件每轮最多 4 个、单个最多 64 KiB、合计最多 128 KiB。只接受文本类扩展名，`xlsx`、`docx`、`pdf`、`zip` 等二进制文件会立即拒绝并提示替代做法。
- 面板宽度会按真实 CSS 视口与显示缩放自动校准并持久化；范围位置统一显示为“2-10 行 × B-D 列”，与“共 9 行 × 3 列”的尺寸说明明确区分。

## Excel 操作

- 新增 `fit_range` 工具和面板“适配”入口：对当前已用范围或指定范围同时设置水平对齐、垂直居中，并自动调整列宽和行高。
- 省略 `range` 的整表适配会在执行前解析真实 UsedRange 并建立快照；只有确实生成可完整还原的记录时面板才显示撤销按钮。原范围对齐混合时会逐格保存；范围过大或快照不完整时，适配仍执行但不承诺撤销。
- 读取上限从 2,000 调整为 5,000 个单元格。常规写入、格式、清除和排序仍受 5,000 个单元格上限约束；`autofit_range` 最多调整 5,000 行或列。`fit_range` 只改对齐与行列尺寸，不受单元格数上限约束，但仍受快照维度和 Excel 执行时间影响。
- `format_range` 新增垂直对齐，并把该维度纳入撤销快照。

## 焦点修复

- 修复面板输入后点击工作表时键盘焦点不回 Excel 的问题。面板外鼠标点击会把焦点交给实际被点击的 Excel 窗口；面板内输入、面板内 `Ctrl+A` 和工作表选区保持独立。
- 新增 `scripts/verify-pane-focus.ps1`，使用真实鼠标和键盘输入验证焦点交接、工作表 `Ctrl+A`、面板输入及相邻行为。脚本会接管前台输入，运行前必须保存工作簿且不要操作键鼠。

## 安全与兼容性边界

- 仅支持 Windows 桌面版 Microsoft Excel；不支持 WPS 表格、Excel 网页版或 Excel for Mac。
- 需要 .NET Framework 4.8、Microsoft Edge WebView2 Runtime 和 UAC 管理员授权。管理员权限用于机器级托管 COM 注册，Excel 加载项登记仍只影响当前用户。
- ZIP 不是 MSI/EXE，也没有代码签名、自动更新或静默安装功能。下载后请先验证 SHA-256。
- 模型请求由加载项进程发送到你配置的服务商；提示词、工作簿结构、读取结果以及主动附加的图片和文本文件内容可能离开本机。
- 默认逐项审批仍是建议设置。面板“适配”是用户直接触发的确定性操作，不经过模型审批；重要工作簿仍应先备份并人工复核。

## 安装

1. 在 [GitHub Release](https://github.com/aEboli/Office-helper/releases/tag/v0.2.0) 下载 ZIP 与 `.sha256` 文件。
2. 比较 ZIP 的 SHA-256 与 sidecar 内容。
3. 解压 ZIP，关闭 Excel，并从解压根目录运行：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1 -Action install
   ```

4. 接受 UAC 提示，重新打开 Excel，再在 **ChatSheet** 选项卡中打开面板。

发行包安装不需要 .NET SDK 或 Node.js；从源码构建仍需要 .NET SDK。Release 页面提供的 ZIP 和 sidecar 将与 `v0.2.0` 标签指向的提交一起核验。
