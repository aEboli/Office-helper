# v0.10.3.22 一键安装命令编码兼容修复

发布日期：2026-11-17。

本补丁修复 `v0.10.3.21` 在线安装引导脚本的 UTF-8 BOM 兼容问题，保留该版的 Word/WPS Writer 只读上下文修复，以及此前工具调用修复。加载项、侧栏、下载入口和包内文档统一为 `0.10.3.22`。

## 修复内容

Windows PowerShell 5.1 以文件方式执行带 UTF-8 BOM 的脚本可以正常工作，但通过 `irm | iex` 执行原始响应文本时，BOM 可能被保留为脚本内容，导致 `[CmdletBinding()]` 和 `param` 解析失败。本次公开下载实测复现了这条路径。

在线引导脚本现使用无 BOM 的 ASCII 编码，兼容本地 `-File` 和网络文本管道执行。安装菜单与主安装脚本继续使用原有中文。安装器回归新增直接对原始 UTF-8 字节解码后执行 `Invoke-Expression` 的检查，覆盖先前文件读取会自动剥除 BOM 而遗漏的问题。

本版继续支持下载最新正式版、指定带或不带 `v` 的版本号、核对 SHA-256、验证发行目录、同时保留 ZIP 与校验文件，以及报告包内安装失败并清理临时目录。Word/WPS Writer 的能力探测只查询成员名，不执行原生 `Undo`；其余工具调用修复见 `docs/releases/v0.10.3.21.md` 和 `docs/verification-word-readonly-context.md`。

## 安装与更新

先保存并完全退出 Excel、Word 和 WPS，再在 Windows PowerShell 中执行：

```powershell
irm https://raw.githubusercontent.com/aEboli/Office-helper/main/scripts/install-online.ps1 | iex
```

也可以下载本页的 `ChatSheet-v0.10.3.22-win.zip` 与 `ChatSheet-v0.10.3.22-win.zip.sha256`，核对 SHA-256 后完整解压，运行 `install.bat`。下载引导脚本后可固定版本并保留下载：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-online.ps1 -Version v0.10.3.22 -KeepDownload
```

接受 UAC 后完成安装，再重新打开宿主。现有设置和安装目录 `%LOCALAPPDATA%\ChatSheet\app` 继续沿用；发布本身不会自动替换已安装的插件。

## 支持与数据边界

这是 Windows 10/11 的预构建 COM 加载项 ZIP，支持桌面 Microsoft Excel、Microsoft Word、WPS 表格和 WPS Writer，需要 .NET Framework 4.8 与 WebView2 Runtime；安装端不需要 .NET SDK 或 Node.js。安装/卸载需要 UAC，它不是 MSI/EXE，未进行代码签名，不支持 macOS 和 Office 网页版。

ZIP 哈希以同名 `.sha256` 为准，包内文件哈希见 `SHA256SUMS.txt`。使用模型时，请求所需的文档/工作簿内容、提示词和附件可能发送给配置的服务商；请遵循相应隐私、计费政策，并备份和复核重要内容。
