# v0.10.3.16 Word 写入与格式规范

本版本完善 Word/WPS Writer 的文档起草、选区改写和格式处理，并更新 Office-helper 仓库与 Windows 发布文档。

## Word 文档写入

- 起草内容写入当前插入光标；明确选区改写时替换该范围。非空选区、Story 或段落目标不明确时先询问，避免误改全文或其他文档区域。
- Word 发送请求会等待整轮文档操作结束，面板在操作完成前保持繁忙状态，并显示完成或停止结果。
- 写入后读取文档结果进行核对。段落格式工具支持按字符数设置首行缩进，并读回检查实际值；只有能创建可靠快照时才提供撤销。
- 审批模式可在设置中选择全自动、逐项审批或每轮审批；结构性修改仍按工具风险单独处理。

## 按点名格式排版

格式约定只在用户明确指定文种、版式或标准后触发。仅凭中文或英文内容不能推断版式；原文档结构会保留，格式变体不明确时先澄清。

- 中文一般书信可按常见惯例将称呼顶格、正文首行缩进两字，并把祝颂语、署名和日期放在文末；落款通常靠右。一般书信通常不另加居中标题。这是惯例，不是统一强制标准。
- 英文商务信函 full block 通常各部分左对齐，正文不缩进并以空行分段；modified block 会把日期及结尾敬语、署名移到页面中部附近，正文仍左对齐且不缩进。
- 中英文称呼与开场遵循各自语境。中文“您好”“冒昧打扰”等表达不逐词翻译成英文；具体标点和机构要求以用户点名的地区、组织或标准为准。
- 只格式化本轮新增或用户明确指定的段落。标题居中、二级标题/标签位置和落款对齐等细节仅在被点名格式要求时应用，不凭语言或文风自行补加。

## 安装与验证

Windows 用户下载 `ChatSheet-v0.10.3.16-win.zip` 和同名 `.sha256` 文件，先校验 SHA-256，再解压运行 `install.bat`。安装器会更新 Excel/WPS 表格与 Word/WPS Writer 加载项；覆盖安装前请保存工作并退出 Office/WPS 宿主。

本版本发行验证包含 Release 构建、Word 工具和格式回归、Web 测试、OpenSpec 严格校验、包内 SHA-256 清单与 ZIP sidecar 校验。Microsoft Word/WPS Writer 的桌面加载仍需在目标宿主版本中确认；发行包不承诺所有宿主功能完全一致。

本机 Microsoft Word 与 WPS Writer 的 COM 文档工具冒烟测试均通过，覆盖文档读取、选区替换并读回、快照撤销、光标插入及撤销。加载项功能区仍需重启宿主后在实际 UI 中确认。
