# ChatSheet v0.2.1

`v0.2.1` 修复 `v0.2.0` 中面板“适配”的撤销与恢复不可用的问题，并让任务进行中可以继续输入（新输入排队执行），同时把思考档位的界面文案改为与协议参数一致的英文原名。

## 修复：面板“适配”可以撤销和恢复

`v0.2.0` 中点击面板“适配”后，提示上会出现“撤销”按钮，但点击后报“找不到该操作记录，可能已超出保留范围”，恢复同样失败。

成因有两处，各自单独看都合理，组合后就产生了“按钮存在但注定失败”的结果：

- `fit_range` 允许省略 `range` 并在执行时取该表的已用范围，而面板“适配”正是这样调用的。撤销快照必须在操作前采集，但执行器当时直接读取参数中的 `range`；参数里没有地址，快照采集放弃，撤销记录未登记。
- `sheet.fit` 通道无条件回传撤销标识，不检查记录是否真的登记成功。

本版的修改：

- 执行前先把隐式范围解析回参数，使快照有地址可采。解析失败仍沿用原路径转换为结构化错误，不改变既有错误契约。
- 只有确实登记成撤销记录时才回传撤销标识。宁可不显示按钮，也不显示一个注定失败的按钮——后者会让用户误以为改动可以回退。
- 确实无法撤销时（范围过大、保不住可完整还原的排版快照），在同一条提示中说明原因并明确“适配本身已经生效”。只缺按钮而不给原因会被当作故障。

原范围对齐逐格不同时，撤销会逐格写回原值，不会把原有排版抹平。

## 新增：任务进行中的输入排队

- 任务进行中输入框不再禁用。此时提交的内容进入队列，上一轮结束后自动继续执行，无需再次点击。
- 排队消息立即显示在对话流中，以虚线气泡与已发送消息区分，并显示队列位次；每条可单独取消。取消会保留原文并标记为未发送，便于复制重发。
- 发送按钮由两种含义扩展为三种：空闲时为“发送”，处理中且输入框有内容时为“加入队列”，处理中且输入框为空时为“停止”。按钮的图形、悬停说明和无障碍名称随含义同步变化。
- “停止”会连带取消整个队列，并说明取消了多少条；否则停止当前一轮后又自动执行下一条排队输入，等同于没有停止。开始新会话同样会清空队列。
- 加载项仍然同一时刻只执行一轮。附件在入队时即与该条消息绑定，之后添加的附件属于后续消息。

## 变更：思考档位使用英文原名

思考档位在界面上显示为 `Off`、`Minimal`、`Low`、`Medium`、`High`、`XHigh`、`Max`，与 OpenAI `reasoning_effort`、Anthropic `output_config.effort`、Gemini `thinking_level` 的取值逐字一致，便于对照官方文档与请求日志排查。档位的中文说明文字保留。

档位的映射与降级行为没有变化：不被目标模型支持的档位仍会就近降级。

详细实现记录：[输入排队、适配撤销修复与英文思考档位](../changes/2026-08-25-input-queue-and-fit-undo.md)。

## 升级方式

`v0.2.0` 的用户按 [Windows 发行包安装说明](../windows-release-install.md) 的升级步骤执行即可：关闭 Excel，在新解压目录运行安装脚本覆盖安装。设置、密钥与面板宽度保存在 `%LOCALAPPDATA%\ChatSheet\` 下，不会被覆盖安装清除。

Excel 加载的是安装目录中的加载项程序集，因此必须完成安装并重启 Excel，上述修复才会生效。

## 安全与兼容性边界

与 `v0.2.0` 一致，本版没有扩大权限或网络边界：

- 仅支持 Windows 桌面版 Microsoft Excel；不支持 WPS 表格、Excel 网页版或 Excel for Mac。
- 需要 .NET Framework 4.8、Microsoft Edge WebView2 Runtime 和 UAC 管理员授权。管理员权限用于机器级托管 COM 注册，Excel 加载项登记仍只影响当前用户。
- ZIP 不是 MSI/EXE，也没有代码签名、自动更新或静默安装功能。下载后请先验证 SHA-256。
- 模型请求由加载项进程发送到你配置的服务商；提示词、工作簿结构、读取结果以及主动附加的图片和文本文件内容可能离开本机。
- 输入排队不改变审批策略：队列中的每条消息在执行时仍按当前审批设置逐项征求同意。默认逐项审批仍是建议设置，重要工作簿仍应先备份并人工复核。

## 安装

1. 在 [GitHub Release](https://github.com/aEboli/Office-helper/releases/tag/v0.2.1) 下载 ZIP 与 `.sha256` 文件。
2. 比较 ZIP 的 SHA-256 与 sidecar 内容。
3. 解压 ZIP，关闭 Excel，并从解压根目录运行：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1 -Action install
   ```

4. 接受 UAC 提示，重新打开 Excel，再在 **ChatSheet** 选项卡中打开面板。

发行包安装不需要 .NET SDK 或 Node.js；从源码构建仍需要 .NET SDK。Release 页面提供的 ZIP 和 sidecar 将与 `v0.2.1` 标签指向的提交一起核验。
