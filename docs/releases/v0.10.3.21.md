# v0.10.3.21 Word 只读上下文修复与命令安装器更新

发布日期：2026-11-17。

本版将 Word/WPS Writer 的误撤销修复，以及此前仅更新到 `main` 的工具调用修复，纳入同一 Windows 发行包。Excel 与 Word 加载项、侧栏回退版本和下载入口统一为 `0.10.3.21`。

## 更新内容

- **修复只读查询误撤销正文**：WPS Writer 在按属性探测 `Undo` 时仍可能执行原生撤销，导致对话开始、摘要刷新或结构读取时，刚输入或粘贴的正文消失。现通过 `IDispatch.GetIDsOfNames` 查询成员是否存在，不读取属性或执行方法；每次能力摘要只探测一次。Microsoft Word 同步验证正文和原生撤销/重做记录保持完整。
- **纳入此前的工具调用修复**：Excel 写入前完整校验矩阵和格式参数，分页读取、分块写入与核验沿用原工作表；Word 修复嵌套表格定位、单元格替换残留和读回失败误报；停止或关闭面板后不执行迟到回调；修复流式 UTF-8 解码、重复终态、并行调用结果配对和示例文本误执行。详见仓库中的 `docs/verification-tool-call-audit.md`。
- **更新命令安装器**：默认查询 GitHub 最新正式版，下载 ZIP 和 SHA-256 文件并校验后执行安装。Windows PowerShell 下载使用基础解析；`-Version` 接受 `0.10.3.21` 或 `v0.10.3.21`；解压目录必须匹配发行版本。`-KeepDownload` 同时保留 ZIP 和校验文件，临时解压目录始终清理；包内安装失败会明确返回错误。
- **更新安装说明**：README、Windows 安装指南、发行包内说明和侧栏版本保持一致；纠正安装指南中已过时的默认审批描述，默认自动执行，可在设置中切换为逐项或每轮审批。

## 安装与更新

下载本页的 `ChatSheet-v0.10.3.21-win.zip` 和 `ChatSheet-v0.10.3.21-win.zip.sha256`，核对 SHA-256，完整解压后运行 `install.bat`。也可以在 Windows PowerShell 中运行：

```powershell
irm https://raw.githubusercontent.com/aEboli/Office-helper/main/scripts/install-online.ps1 | iex
```

请先保存并完全退出 Excel、Word 和 WPS，接受 UAC 后完成安装，再重新打开宿主。发布新版不会自动替换本机已经安装的 DLL，也不会让运行中的宿主立即生效。现有设置与安装目录 `%LOCALAPPDATA%\ChatSheet\app` 继续沿用。

发行包是 Windows 10/11 的预构建 COM 加载项 ZIP，支持桌面 Microsoft Excel、Microsoft Word、WPS 表格和 WPS Writer，需要 .NET Framework 4.8 与 WebView2 Runtime；安装端不需要 .NET SDK 或 Node.js。它不是 MSI/EXE，未进行代码签名，不支持 macOS 或 Office 网页版。ZIP 的实际哈希见同名 `.sha256`，包内文件哈希见 `SHA256SUMS.txt`。
